How to use this page

A quick walkthrough — click outside this box, or the X below, to close.

1. Search first

Type a stock code, product name, or category into the box at the top. Results update as you type — it's a fuzzy search, so small typos are fine. Use the filter chips (vertical, active/inactive, category) underneath to narrow things down.

2. Found it? Use the button on that row

Every result has buttons on the right:

• Reactivate this code — the item already exists but is switched off. This brings it back.

• Use as template — found something close but not exact? This starts a new-code request pre-filled from it.

• Add supplier — the product's right, it just needs pricing from a different supplier.

3. Need several things at once?

Tick the checkbox on the left of each result you need (or "Select all visible"), then click "Request selected" in the bar that appears at the bottom. One email covers everything you've picked, instead of separate requests for each.

4. Genuinely nothing exists yet?

Scroll down and click "Request a brand new stock code". It'll double-check against close matches first — if none of those fit, you'll get the full form to fill in.

5. Filling in the form

Fields marked with a red * are required. Fields that are greyed out and already filled in (like Stock Code on a Reactivate) are just for reference — you don't need to touch them. When you're done, click the button at the bottom — this opens a pre-filled email in Outlook. Nothing is sent until you personally click Send in Outlook — check the email over first.
